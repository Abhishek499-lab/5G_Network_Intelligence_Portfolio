# Publish this project on GitHub

1. Create a new **public** repository named `5g-network-intelligence` (or a name you prefer).
2. Keep the original source dataset ZIP out of the repository unless its license explicitly permits redistribution.
3. Upload the contents of this folder, preserving the directory structure.
4. Check that `README.md` renders the Mermaid architecture diagram on GitHub.
5. Add the original dataset's publisher citation and license/terms once you have verified them from the source page.
6. In the repository About field, use: `Offline 5G client-measurement forecasting and KPI-proxy warning prototype`.
7. Add topics: `5g`, `machine-learning`, `time-series-forecasting`, `scikit-learn`, `network-analytics`, `python`.
8. Do not upload private credentials, personal data, or any source dataset that cannot be redistributed.

Suggested repository description:

`Offline AI prototype for 5G client-measurement throughput forecasting, KPI-derived degradation warnings, and alert episode analysis.`
