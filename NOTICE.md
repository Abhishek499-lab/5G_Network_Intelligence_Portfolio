# Data and artifact notice

The original measurement dataset is intentionally not included in this repository bundle. Users must obtain it from its original publisher and follow the publisher's access, citation and redistribution terms. Sample smoke-test CSVs are included only to demonstrate the expected input/output schema; inspect them before public release to ensure they contain no sensitive or identifying information.

The included `.joblib` files are reference model artifacts produced by the V6.6 pipeline. Load serialized Python models only from a trusted source and use a compatible Python/scikit-learn environment.
